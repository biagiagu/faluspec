# Plantilla FaLuSpec

Esqueleto que se clona para arrancar un proyecto nuevo. Hoy vacio: se completa
al cerrar la fase 0, extrayendo el patron de un proyecto real (nunca copiandolo).

- `backlog/` — un archivo por item
- `docs/` — constitucion, plan, hitos
- `agentes/` — agentes generalizados, sin stack ni cliente
