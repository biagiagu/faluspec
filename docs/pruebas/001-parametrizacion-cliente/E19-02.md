## Historia

Como administrador, quiero que el seed de usuarios cargue a la gente real del cliente con su rol,
para que el primer login de cada uno funcione sin que nadie toque la base a mano.

## Criterios

### E19-02.1 — El seed carga personas, no ejemplos

**Dado** el seed de usuarios iniciales, **cuando** se lo corre contra una base vacía,
**entonces** los usuarios creados son personas reales del cliente, sin nombres de relleno.

- ancla: `apps/api/src/db/seeds/usuarios-iniciales.ts#USUARIOS`
- verifica: `manual`

### E19-02.2 — Todo usuario inicial puede efectivamente entrar

**Dado** los usuarios del seed, **cuando** se los compara con el dominio configurado para el login,
**entonces** todos pertenecen a ese dominio.

- ancla: `apps/api/src/db/seeds/usuarios-iniciales.ts#USUARIOS`
- verifica: `unit` → `usuarios-iniciales.test.ts::todos los usuarios pertenecen al dominio de login`

### E19-02.3 — Correrlo dos veces no duplica ni pisa

**Dado** una base con los usuarios ya cargados, **cuando** se vuelve a correr el seed,
**entonces** actualiza nombre y rol de los existentes y no crea filas nuevas.

- ancla: `apps/api/src/db/seeds/usuarios-iniciales.ts#main`
- verifica: `integracion` → `usuarios-iniciales.itest.ts::es idempotente`
