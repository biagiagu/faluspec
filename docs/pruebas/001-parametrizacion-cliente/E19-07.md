## Historia

Como responsable del despliegue, quiero que cada integración use credenciales de este proyecto y no
las heredadas, para que revocar las viejas no deje la app sin funcionar.

## Criterios

### E19-07.1 — El login con Google funciona con credenciales propias

**Dado** las credenciales creadas para este proyecto, **cuando** alguien del cliente inicia sesión,
**entonces** entra, y ninguna credencial del proyecto anterior interviene.

- ancla: `apps/api/src/plugins/auth-google.ts#authGoogleRoutes`
- verifica: `manual`

### E19-07.2 — La ingesta de pedidos funciona con la cuenta del cliente

**Dado** la aplicación registrada para este proyecto, **cuando** llega un aviso de una venta nueva,
**entonces** el pedido ingresa al sistema.

- ancla: `apps/api/src/plugins/webhooks-woo.ts`
- verifica: `manual`

### E19-07.3 — Ninguna credencial viaja en el repositorio

**Dado** el repositorio, **cuando** se revisan los archivos versionados,
**entonces** ninguno contiene un secreto: los ejemplos de configuración sólo tienen nombres de
variable y valores vacíos.

- ancla: — *(el alcance es el repositorio entero)*
- verifica: `estatica` → chequeo en CI
