## Qué agrupa

Todos los valores que el proyecto heredó del cliente anterior y que tienen que ser reemplazados por
los del cliente nuevo antes de que exista un despliegue de producción. El código está escrito y
probado; lo que falta es el dato.

## Criterios de la épica

### E19.a — No queda ningún valor heredado sin confirmar

**Dado** el repositorio, **cuando** se recorren las marcas de parametrización pendiente,
**entonces** no queda ninguna: ni el placeholder de dominio, ni un `TODO(cliente)`.

- verifica: `estatica` → chequeo en CI

### E19.b — Una base recién creada queda operable para el cliente

**Dado** una base vacía, **cuando** se corren las migraciones y los seeds,
**entonces** todos los catálogos que el producto necesita quedan poblados con datos del cliente,
sin filas de ejemplo ni de relleno.

- verifica: `integracion` → `base-desde-cero.itest.ts::las tablas de catálogo quedaron con datos`
