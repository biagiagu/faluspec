## Historia

Como responsable de la operación, quiero cargar los transportistas que el cliente usa, para poder
despachar un envío indicando con quién sale.

## Criterios

### E19-04.1 — El catálogo de transportistas no queda vacío

**Dado** una base recién sembrada, **cuando** se consulta el catálogo de transportistas,
**entonces** tiene al menos uno, y todos son del cliente.

- ancla: `apps/api/src/db/seeds/base.ts#TRANSPORTISTAS`
- verifica: `manual`

### E19-04.2 — La verificación de base nueva vuelve a exigirlo

**Dado** el chequeo de catálogos sembrados, **cuando** corre contra una base creada desde cero,
**entonces** la tabla de transportistas está en la lista de las que deben tener datos.

- ancla: `ninguna` — el trabajo es el test mismo, ver `verifica`
- verifica: `integracion` → `base-desde-cero.itest.ts::las tablas de catálogo quedaron con datos`

### E19-04.3 — Ningún transportista se recrea por migración

**Dado** una base a la que se le aplican todas las migraciones, **cuando** todavía no corrió el seed,
**entonces** la tabla de transportistas está vacía.

- ancla: `ninguna` — el trabajo es el test mismo, ver `verifica`
- verifica: `integracion` → `base-desde-cero.itest.ts::las migraciones no cargan transportistas`
