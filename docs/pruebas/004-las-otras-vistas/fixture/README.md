# Fixture

Backlog **inventado**, escrito para ejercitar las vistas. No sale de ningún proyecto: es forma pura.

Ejercita a propósito lo que la prueba 003 no pudo:

- **tres épicas**, con `E4 < E7 < E19` — que ordenadas como texto quedan al revés;
- **huecos de numeración** en las tres, porque los identificadores no se reciclan;
- `E19-03` y `E19-10`, que ordenados como texto quedan al revés;
- un **bloqueo declarado en la épica** que heredan dos ítems, y otro **propio de un ítem**;
- ítems **con y sin** `hito`;
- los cuatro estados.
